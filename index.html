Development of GitHub profile

Throughout the program, I've developed a professional GitHub profile. I learned how to Establish it (having a professional profile picture, a Description, etc.), and how to develop it further, (making public and private repositories, how to use them, and how to use specially named ones to add to your profile more, like a better description or link to a portfolio).
